# Sendline 0.5.0

Send HTTP requests from `.http` and `.rest` files in Zed. Select a public/private environment, click a gutter play button, and inspect status, timing, response files, and JavaScript test results in the integrated terminal.

The extension automatically downloads its native backend. Rust, Node.js, and a separate HTTP CLI are not required.

## First use

Zed registry availability requires approval of the registry submission. After Sendline appears in Extensions, install it and open your project folder. Enable `languages.HTTP.code_lens` with the value `on` in Zed settings to display the environment header. Environment choices are also available as code actions when CodeLens is off.

See the [installation guide](https://github.com/Prajwal-ak-0/zed-sendline#install-from-zed) for setup, environment files, examples, and supported request syntax.

## Platforms

- macOS: Apple silicon and Intel.
- GNU/Linux: ARM64 and x86_64, with glibc 2.35 or newer.

Windows, external file bodies, imported or pre-request scripts, asynchronous response handlers, multipart helpers, and cookie persistence are not implemented in this release.

## Verify a manual download

Each platform has an archive and two checksum files. The `.tar.gz.sha256` file verifies the archive. The `.sha256` file without `.tar.gz` verifies the extracted `sendline` executable; the Zed adapter uses that checksum before launching it. Archives include the project license and dependency notices.
