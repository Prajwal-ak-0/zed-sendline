# Sendline 0.6.0

Sendline is now a language-server-only HTTP client. Install the existing HTTP language extension for highlighting and file recognition. Sendline's extension ID is `sendline-http-lsp` and its display name is Sendline HTTP Client.

Click Send Request above an endpoint to execute the current editor text, including unsaved edits. Choose environments beside the header. Cancel an active request from the same file. Code actions provide the same operations when CodeLens is disabled.

Results appear in a private, read-only metadata console with status, timing, size, content type, and links to the response, headers, and response-test report. The console is an editor document. This version does not automatically open a terminal or supply gutter tasks.

The package no longer bundles an HTTP grammar, highlighting queries, runnable queries, or task definitions. It no longer registers a home-cache launcher. Zed supplies its own extension work directory for state and response artifacts. The native backend still downloads automatically and needs no Node runtime or separate HTTP CLI.

Stale actions are rejected before sending. Duplicate clicks cannot send concurrent requests from one document. Closing the document or stopping the server cancels an active operation. Old operations cannot overwrite the state of a reopened document. HTTP errors and failed response tests preserve their response artifacts.

Registry installation awaits approval of the existing submission. The owner must visually inspect this exact candidate in Zed and review the revised submission wording before it is marked ready.
